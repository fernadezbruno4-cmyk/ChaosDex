# CHAOSDEX

Premium, minimal Web3 website for CHAOSDEX — a token-versus-token comparison platform.

> Two tokens enter. One wins.

## Tech Stack

- [Next.js](https://nextjs.org/) (App Router)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/) (animations)
- [Lucide React](https://lucide.dev/) (icons)

## Getting Started

### Prerequisites

Node.js (v18 or newer) and npm are required.

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for production

```bash
npm run build
npm run start
```

## Deployment on Vercel

1. Push this repository to GitHub.
2. Log in to [Vercel](https://vercel.com).
3. Click "Add New" → "Project" and import the GitHub repository.
4. Vercel detects Next.js automatically — use the default build settings.
5. Click "Deploy".
